# PX Compass

PX Compass is an independent, community-built gateway to the PrismaX ecosystem. It helps validators, operators, contributors, robot owners, and newcomers find the right official PrismaX destination quickly.

## Features

- Role-based paths for validators, operators, contributors, and robot owners
- Searchable directory of official PrismaX destinations
- Local bookmarks and category filters
- PrismaX onboarding resources and current updates
- Official brand-kit visuals and ecosystem carousel
- Responsive layouts for desktop and mobile

## Run locally

Requires Node.js 22.13 or later.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
